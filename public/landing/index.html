Built to stop itself

The part that says no.

An autonomous trader is only as good as its brakes. Seven independent guards — plus a dry-run default — sit between a signal and a filled order, and any one of them can veto the trade.

HALT

Circuit Breaker

Daily loss limit ($10), hourly trade cap (20), and a hard stop after 5 consecutive failures.

SL/TP

Position Lifecycle Manager

Stop-loss and take-profit enforced over live WebSocket, plus partial and time-based exits with IndexedDB crash recovery.

SIZE

Kelly Criterion Sizing

Drawdown-adjusted fractional Kelly with high-water-mark tracking, so size shrinks as the book bleeds.

GAS

Gas Oracle

Skips any trade where Polygon gas would eat more than 50% of the expected profit.

DEPTH

Order Book Depth

Caps order size to the liquidity actually resting on the book instead of the size you wished for.

EDGE

Edge Tracker

Compares realized against predicted edge with exponential decay to catch a strategy going stale.

REJECT

Rejection Tracker

Watches exchange rejection patterns as an early warning of signal or credential degradation.

DRY

Dry Run Mode

The default. Every strategy runs end-to-end and logs the trade it would have placed — no funds at risk.

Sixty seconds to dry run

Clone it, key it, watch it think.

Dry run is the default — the bot will run every strategy and log the trades it would have made without touching your balance. Flip it live only when the log looks right.

install
# clone and install
git clone https://github.com/Deegan4/alphapolybot.git
cd alphapolybot
npm install

# configure
cp .env.example .env
# add VITE_WALLET_SEED_PHRASE + VITE_OPENROUTER_API_KEY
run
npm run dev            # dev server on :4000
npm test               # 511 tests
npm run build          # production build
  1. Create a dedicated trading wallet — never your main one.
  2. Fund it with USDC.e + MATIC on Polygon.
  3. Grab an OpenRouter API key for the LLM strategy.
  4. In the app: Settings → Wallet → Approve Tokens (3 contracts).
  5. Start in dry run and read the Activity tab.
  6. Disable dry run only once the logged trades look right.
Use USDC.e — the bridged token, not native USDC. The exchange only sees bridged USDC.e, so native USDC will sit in the wallet doing nothing.
